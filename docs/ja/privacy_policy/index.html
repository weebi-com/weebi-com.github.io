プライバシーポリシー

April 1, 2024

weebi.com によって収集された個人データは、お客様が個人データを残した目的に従ってのみ使用され、セネガルのデータ保護法に準拠します。このプライバシー ポリシーでは、当社が個人情報を収集および処理する方法を規定します。

どのような機密情報を収集しますか?

デフォルトではなし。 Weebi はサインアップした場合にのみデータを収集します。その後、自動クラウド バックアップには次のような情報が保存されます。

ユーザー

  • ファーストネーム
  • 姓
  • 電子メール
  • 暗号化されたパスワード

ブティック

  • 名前
  • 電子メール
  • 電話
  • 住所
  • 国

記事（製品）

  • 指定
  • 価格
  • 料金
  • 写真
  • カテゴリ

連絡先

  • ファーストネーム
  • 姓
  • 電子メール
  • 電話
  • 国

チケット

  • 日付
  • ブティックID
  • アイテム
  • 接触

情報をどのように保護しますか?

この情報は安全なネットワークの背後に保管され、そのようなシステムへの特別なアクセス権を持ち、情報の機密性を保つ必要がある限られた数の人物のみがアクセスできます。

データを第三者と共有しますか?

当社は、お客様の個人を特定できる情報を外部の第三者に販売、取引、または転送することはありません。さらに、当社の Web サイトやブログには、サードパーティの製品やサービスが含まれたり、提供されたりすることはありません。

データの使用

当社は、機密かつ匿名化された信用度スコアを計算するために、お客様の事業活動からの特定の情報を使用する場合があります。 たとえば、売上高と、ビジネスをその経済的背景に置くおおよその場所 (近隣) などです。 このスコアは金融機関にとって重要な基準であり、ビジネスに合わせた信用オファーを取得するプロセスを迅速化できます。 金融機関がお客様にオファーを希望する場合は、追加情報を共有する前にお客様の同意を求めます。
